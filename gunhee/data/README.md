# 대학도서관 열람실 위치 메타데이터

데이터기준일자: **2026-11-14 (Asia/Seoul)**. 해커톤용 자체 정리 데이터이며 공공데이터포털의 공식 표준데이터 또는 대학의 공식 배포 데이터가 아니다. 실시간 잔여석, 이용 상태, 개인 이용 시각은 저장하지 않는다.

## 현재 수집 범위

| 대학 | 열람실/공간 레코드 | 알려진 총 좌석 수 | 개별 좌석 행 | 좌표 제공 열람실 비율 |
|---|---:|---:|---:|---|
| 고려대학교 | 0 | 미수집 | 0 | 산정 불가 |
| KAIST | 4 | 미상 | 0 | 0% |
| 충남대학교 | 7 | 2,268 | 0 | 0% |

고려대 [robots.txt](https://librsv.korea.ac.kr/robots.txt)는 `User-agent: *`, `Disallow: /`이다. 요청 규칙에 따라 중단했으며 열람실·좌석 API와 배치도 이미지는 호출하지 않았다. `source_metadata/korea_robots.json`에 확인 결과를 남겼다. 현재 좌석 CSV는 헤더만 있고 JSON은 `[]`이다. 고려대 결과가 누락된 부분 구축 상태이므로 좌석 추천 학습용 데이터로 바로 사용할 수 없다.

KAIST [층별/시설안내](https://library.kaist.ac.kr/libGuidance/libUse/fcltyGuidance.do)에서 3·4층 각각의 한방향열람실, 개인열람석을 공간 단위로 작성했다. 한 층에 같은 종류의 공간이 여러 곳 있을 수 있어 각 레코드는 물리적인 방 하나를 보장하지 않는다. 그룹스터디룸은 이번 열람 좌석 범위에서 제외했다. 자유석이라는 배경 설명은 있으나 이 안내만으로 공간별 배정방식을 확인할 수 없어 해당 필드는 비웠다. 좌석 수·번호·좌표는 합성하지 않았다.

충남대 [열람실 안내](https://library.cnu.ac.kr/webcontent/info/312)의 표와 사용자 제공 자료를 대조했다. 표의 일반/노트북 구역을 각각 레코드로 만들었다. 도서관명은 특정 건물명을 추정하지 않고 `도서관`으로 기록했다. 아우름의 배정방식과 표에서 `-`/`·`인 노트북 사용 여부는 미상으로 비웠다. 원문에 2026-11-16~2026-12-18 기간의 운영시간 변경과 아우름 운영 중단 안내가 있어 상시 운영시간으로 옮기지 않았다. 2,268석은 아우름 223석을 포함한 표기 정원 합계이며 현재 이용 가능한 좌석 수가 아니다.

## 파일

- `열람실표준데이터.csv/.json`: 열람실 또는 구역 1행.
- `열람실좌석위치데이터.csv/.json`: 좌석 1개 1행. 현재 빈 템플릿.
- `열람실시설위치데이터.csv/.json`: 직접 실측할 시설 위치. 현재 빈 템플릿.
- `좌석수검증결과.csv/.json`: 열람실별 표기 좌석 수, 수집 행 수, 비교 가능 여부.
- `validation.json`: 대학별 집계, 컬럼별 결측치 수, 좌표 오류, 인코딩·스키마 검증 결과.
- `source_metadata/`: 허용 목록으로 정제한 수집 중간 결과와 robots 차단 근거. API 응답 원문은 저장하지 않음.
- `images/KAIST/KAIST-{1..4}F.jpg`: 층별 안내도. 열람실ID별 사본도 같은 디렉터리에 제공.
- `preview/`: 실제 좌표가 있을 때 생성되는 사각형 중첩 이미지. 현재는 미생성 사유만 기록.

CSV는 **UTF-8 BOM**, 한글 헤더이며 마지막 컬럼은 항상 `데이터기준일자`이다. JSON은 UTF-8, 동일한 한글 키를 가진 객체 배열이다. CSV의 빈 셀은 미상/미제공이며 JSON에서는 `null`이다. 빈 값은 0 또는 N을 뜻하지 않는다. 열람실·좌석·시설 ID는 문자열이다. KAIST/CNU 접두 ID는 서비스 공식 ID가 아닌 이 데이터셋 내부 식별자다. 파일 수동 편집 후 빌드를 다시 실행하면 덮어쓰므로 실측본은 별도 보관해야 한다.

## 컬럼 정의

### 열람실표준데이터

| 컬럼 | 정의 |
|---|---|
| 대학명, 도서관명 | 기관과 도서관 이름 |
| 열람실ID, 열람실명, 열람실영문명 | 구역 식별자와 명칭. 미상 영문명은 공란 |
| 층 | `B2`, `B1`, `1F` 등. 미확인 시 공란 |
| 전체좌석수 | 표기 정원. 좌석 현재 이용 상태와 무관한 정수 |
| 좌석배정방식(지정석/자유석) | 공식 안내로 확인한 지정석/자유석. 미상 공란 |
| 노트북사용가능여부(Y/N) | 허용 Y / 금지 N / 미상 공란 |
| 운영시작시각, 운영종료시각 | 상시 운영 시각. 현재 레코드는 확인 범위상 공란 |
| 1회최대이용시간(분) | 상시 적용이 확인된 최대 이용 분. 현재 공란 |
| 배치도이미지URL | 원본 안내도/배치도 URL |
| 배치도가로픽셀, 배치도세로픽셀 | 다운로드한 이미지의 실제 픽셀 크기 |
| 좌석좌표제공여부(Y/N) | 이 데이터셋에서 개별 좌석 좌표 제공 여부 |
| 출처URL | 확인한 안내 페이지 또는 열람실 API URL |
| 데이터기준일자 | 해당 레코드 수집/대조일, `YYYY-MM-DD` |

### 열람실좌석위치데이터

| 컬럼 | 정의 |
|---|---|
| 대학명, 도서관명, 열람실ID | 열람실 데이터와 연결. 조인 키는 대학명+열람실ID |
| 좌석ID, 좌석번호 | 원본 좌석 식별자와 표시 번호. 문자열 |
| X좌표, Y좌표 | 원본 API의 xpos/ypos. 배치도 픽셀 좌표라는 가설이며 현재 검증되지 않음 |
| 가로, 세로 | 원본 API의 width/height. 픽셀 단위 가설이며 미검증 |
| 정규화X(0~1), 정규화Y(0~1) | X/이미지 가로, Y/이미지 세로. 이미지/좌표 미상이면 공란. 범위를 강제로 잘라내지 않음 |
| PC좌석여부 | 원본 pcSeatYN의 Y/N. 미상 공란 |
| 좌석유형 | 직접 확인된 책상 형태 등. 원본에 근거 없으면 공란 |
| 출처URL, 데이터기준일자 | 좌석 API 주소와 수집일 |

고려대 수집기가 이후 허용되어 실행되더라도 원점이 좌상단인지, 좌표가 사각형 좌상단인지, 표시용 스케일·오프셋이 있는지는 미리보기로 검증해야 한다. 현재 이를 확인한 사실은 없다. 이미지 범위 검증만으로 좌표계 정합성이 보장되지 않는다.

### 열람실시설위치데이터

| 컬럼 | 정의 |
|---|---|
| 대학명, 도서관명, 열람실ID | 열람실 연결 정보 |
| 시설ID | 실측자가 부여하는 고유 식별자 |
| 시설유형(화장실/출입구/에어컨/창문/정수기/콘센트/기둥) | 해당 유형 중 하나 |
| X좌표, Y좌표 | 검증된 배치도 좌표계에서 시설의 대표 점. 실측 시 원점과 축을 비고에 명시 |
| 비고 | 측정 방법, 지점 의미, 오차 및 추가 설명 |
| 데이터기준일자 | 실측일, `YYYY-MM-DD` |

KAIST 안내도는 입체 일러스트이며 실제 거리·방향·층별 축척을 제공하지 않는다. 좌석 사각형을 자동 추출하거나 조명·에어컨·화장실 거리, 책상 형태를 추정하지 않았다. 1·2·3층은 870×564, **4층은 870×517**이다. 로컬 사본은 RGB JPEG로 재인코딩했으며 원본 픽셀 크기를 보존했다. 이미지 이용조건은 원 출처를 따른다.

## 재실행

Python 3.10 이상(이번 검증은 3.12). `gunhee/`에서 실행한다.

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/collect_korea.py
# robots 금지 시 종료코드 2. API 수집은 수행하지 않는다.
.venv/bin/python scripts/static_sources.py
.venv/bin/python scripts/build_dataset.py
.venv/bin/python scripts/collect_public_api.py
.venv/bin/python -m unittest discover -s scripts -p 'test_*.py'
```

요청 목적을 User-Agent로 알리고 요청 종료 후 다음 요청까지 최소 1.1초 대기한다. 실패 시 최대 2회 재시도한다(총 3회). 로그인/리다이렉트/접근 제한·지정 엔드포인트 실패 시 다른 경로를 탐색하지 않는다. 각 스크립트는 독립 실행한다. 고려대 차단을 우회하는 옵션은 없다.

공공데이터포털 [15142580](https://www.data.go.kr/data/15142580/openapi.do), 베이스 URL `https://apis.data.go.kr/B551982/plr_v2`는 확장용이다. 이번에는 `DATA_GO_KR_KEY`가 없어 미호출했다. 연결 문서만으로 상세기능 경로와 항목별 응답 스키마를 확정하지 못해 임의 경로를 넣지 않았다. 키가 있을 때 공식 활용명세에서 확인한 아래 설정을 `--config`로 제공해야 한다. 이 수집기의 실제 인증 호출은 검증되지 않았다.

```json
{
  "operation": "공식문서에서확인한상세기능명",
  "fields": {"공식영문열람실ID필드": "열람실ID", "공식영문총좌석수필드": "전체좌석수"},
  "stdgCd": "선택한법정동코드"
}
```

매핑 가능한 대상은 도서관ID, 도서관명, 열람실ID, 열람실명, 층, 전체좌석수, 주소, 위도, 경도뿐이다. 반드시 정적 원본 필드만 매핑한다. API 응답 원문과 인증키는 기록하지 않으며 이 선택 데이터는 대학 CSV에 자동 병합하지 않는다.

## 검증 결과와 남은 작업

CSV의 BOM·정확한 컬럼 순서·날짜 마지막 컬럼·행 수·ID 중복을 확인했다. 열람실별 비교 표의 11개 행은 모두 좌표 미제공으로 비교 불가다. 따라서 관측된 좌석수 불일치가 0건이라는 것은 정원과 좌석 행 수의 일치를 입증하지 않는다. 열람실 영문명 11건, 전체좌석수 4건, 배치도 7건 등 미상 값은 의도적으로 비웠으며 `validation.json`에 모든 컬럼의 결측 수가 있다.

고려대 수집 허용 출처 또는 별도 제공 자료를 확보한 후 개별 좌석과 3~4개 방의 좌표 중첩 미리보기를 검증해야 한다. 현재 정합성 검증·스케일/오프셋 보정은 수행 불가다. 좌석·시설 실측과 환경 특성 라벨링을 완료해야 거리 기반 추천에 사용할 수 있다.
