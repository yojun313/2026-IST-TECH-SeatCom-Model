## 기능별 판단

- **도서관·열람실 탐색:** 27개관의 마스터와 94개 열람실 레코드가 있어 목록/정적 정원 표시 가능. 정원은 출처·기준일이 다른 값이 포함되어 각 `build_report.json`을 확인해야 한다.
- **좌석 지도 표시:** 좌표 후보가 있는 11개관은 좌석 버튼/평면 이미지 위에 후보 좌석을 그리는 기반이 있다. 현재 2,111건 모두 `model_candidate`이므로 사람 검수와 원본ID/좌석번호 정합 전에는 예약 선택용 실좌석으로 보장하지 않는다. 지도 프레임 34개 중 로컬 이미지 경로는 2개뿐이다. 재사용 조건을 확인하지 못한 원본 이미지는 복제하지 않아, 나머지 지도 배경은 별도 허가/원본 확보가 필요하다.
- **시설 기반 좌석 추천:** 화장실·출입구·계단·승강기 후보 73건으로 제한적인 거리 점수 실험은 가능하지만 모두 후보 수준이며 층/프레임/통로 연결 검수가 필요하다. 에어컨·조명·콘센트·창문/전망/책상 특성은 좌석 단위 데이터 0건.
- **개인 취향 학습:** 노트북 가능 21, 칸막이 7, 키보드 가능 1개의 열람실 단위 특성만 있다. 좌석 단위 특성 및 실제 선택·착석 로그는 이 데이터셋에 없으며, 사용자 취향 모델의 학습 데이터도 아직 구축되지 않았다.
- **현재 위치 기반 도서관 추천:** 공식 좌표가 0/27이라 거리 계산 불가. 주소가 있어도 좌표 추정은 포함하지 않았다.
- **실시간 좌석 현황:** 이번 정적 데이터셋의 범위가 아니다. 실시간 상태는 별도 API에서 검증된 경우만 서비스에서 사용하며 좌석별 상태를 정적 파일에 저장하지 않는다.

## 검증 및 파일 형식

- 27개 dataset.json 모두 target_schema.json v1.1 검증 통과.
- 27개관 × 11개 배열의 개별 JSON/CSV 파일 확인: JSON 배열 값 일치, 모든 테이블에서 한글 헤더 일치, UTF-8 BOM, 행 수 일치, 마지막 컬럼 `데이터기준일자` 확인.
- Chrome 렌더링 확인: 용인 보라의 134개 좌석에서 화면 DOM 좌표와 기존 좌표 후보가 모두 일치했다. 화면에 번호가 표시된 57개만 좌석번호에 연결했다. 사용 중 표시는 번호 대신 `배정`으로 가려져 나머지는 미상이며, 좌석 상태·색상·시각은 저장하지 않았다.
- 통합 학습용 테이블은 `libraries/_unified/`에 JSONL로 재생성했다. 학습 로더는 [`load.py`](libraries/load.py), 재생성 스크립트는 [`build_unified.py`](libraries/build_unified.py), 전체 표 CSV 생성기는 [`export_csv.py`](libraries/export_csv.py), 집계표는 [`coverage.csv`](libraries/_unified/coverage.csv).
- CSV는 표 열이 넓어 별도 JSON 링크도 함께 제공한다. 다수의 빈 CSV는 아직 근거 데이터가 없다는 뜻이며 시설의 실제 부재를 의미하지 않는다.
