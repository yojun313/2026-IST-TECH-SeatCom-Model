# SeatViz — SeatCom 데이터셋 뷰어

도서관 실데이터 27관과 합성 데이터(환경·사용자·세션·이벤트)를 보는 웹 화면입니다.
**백엔드 서버에 통합되어 있습니다.** 따로 실행할 필요가 없습니다.

- 주소: **백엔드 서버 주소의 `/`** (기본 `http://서버주소:8001/`). 백엔드 API(`/api/v1/...`, `/health`, `/docs`)가 먼저 매칭되고 나머지 경로가 뷰어로 갑니다.
- 데이터: 백엔드와 같은 SQLite(`DATABASE_PATH`)의 카탈로그 테이블을 **읽기 전용**으로 읽습니다. MongoDB는 필요 없습니다.
- 붙이는 위치: `backend/main.py` 맨 끝의 `app.mount("/", ...)`. 반드시 모든 API 라우트 뒤에 둡니다.

## 화면

| 경로 | 내용 |
|---|---|
| `/` | 개요: 컬렉션 건수, 27관 표, 합성 생성 정보 |
| `/floor` | **도서관 뷰어**: 실좌석 배치 + 합성 환경 평면도. 시나리오·시간대·좌석 색칠·바닥 히트맵·레이어, 좌석 상세 |
| `/real` | 실데이터: 지도 프레임별 좌석 bbox·시설, 열람실·좌석·시설·특성·출처·구축 보고서 |
| `/users`, `/users/{id}` | 합성 사용자: 카카오톡 관측 프로필 vs 잠재 선호(정답), 세션 이력 |
| `/sessions`, `/sessions/{id}` | 합성 세션: 추천 Top5·선택·비선택 좌석, 이벤트 타임라인, 선택 이유 |
| `/stats` | 특성 분포, 환경 조건, 도서관별 평균, 선택 순위·만족도, 프로필 정확도 |
| `/browse` | 컬렉션 원본 문서 조회(필터 JSON: 필드 = 값, `$in` `$ne` `$gt` `$gte` `$lt` `$lte` `$regex`) |

API는 `/api/...`(문서: `/api/docs`), 상태 확인은 `/healthz`입니다. 모두 읽기 전용입니다.

## 공개 서버 보호

- DB 연결이 `mode=ro`라 뷰어는 데이터를 바꿀 수 없고, 카탈로그 외 테이블(회원 등)은 조회 대상이 아닙니다.
- 동시에 도는 뷰어 질의 수와 질의 하나의 실행 시간을 제한해 같은 프로세스의 추천 API를 보호합니다.
  `VIEWER_MAX_QUERIES`(기본 2), `VIEWER_QUERY_SECONDS`(기본 20)로 조절합니다.
- 필드 이름은 정규식으로 검사하고 값은 모두 SQL 바인딩합니다. `$where`·`$or` 같은 연산자는 거절합니다.
- 개요·통계는 서버 시작 때 백그라운드로 미리 계산해 둡니다(`SEATVIZ_WARM=0`이면 생략, 테스트용).

## 구조

```text
seatviz/app/
├── main.py            # create_app(database_path): 백엔드가 / 에 붙인다
├── db.py              # SQLite 카탈로그 읽기(MongoDB 형태 조회를 필요한 만큼 흉내), 동시성·시간 제한
├── routes/api.py      # JSON API
├── routes/pages.py    # HTML 페이지(하위 경로에 붙일 때를 위해 링크에 base 를 붙임, 지금은 빈 값)
├── templates/         # _layout + 페이지별 템플릿
└── static/            # app.css, common.js(SV.base), floor.js(평면 렌더러), vendor/
```

렌더링 주의: 미터 축척·벽·창·냉방기·조명·콘센트·책상 형태는 합성 값입니다(`합성` 배지). 좌석 bbox·ID와 같은 지도의 출입구·화장실 후보만 실데이터입니다.
