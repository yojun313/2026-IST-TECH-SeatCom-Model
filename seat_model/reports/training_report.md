## 8. 해당 없음(v1 데이터 한계)과 한계

- 해당 없음: 온보딩 설문 특징, laptop_carried, config 우선순위 제약(4단계 c·d·e), 결과 신호 가중치(7단계 W2·W3), IPS·오프폴리시 평가(노출 확률 없음: 로깅 정책이 관측 프로필 점수 상위 5개로 결정적), '노출 없는 선택' 지표.
- 노출 편향: 실제 선택의 81%가 추천 상위 5개 안에서 나왔다. `y_chosen` 지표는 로깅 정책(현재 서비스 규칙)을 흉내 낼수록 높아진다. 그래서 `y_chosen` 지표와 참 효용 지표의 순위가 다를 수 있고, 실제 서비스에서는 A/B 테스트로 확인해야 한다.
- 합성 데이터: 참 효용이 생성기와 같은 선형 형태라 로짓에 유리하다. 실제 사용자 행동에서는 비선형 모델의 이점이 더 클 수 있다.
- 숨은 취향 중 칸막이·출입구 거리는 카카오톡 프로필에 항목이 없다. 착석 기록 추정(5.3)으로만 드러난다.
- 6단계(신경망, GPU)와 7단계 실험은 문서 규칙대로 이 결과를 보고한 뒤 승인받고 진행한다.
